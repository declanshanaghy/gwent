# Gwent Companion — Base Image Prompt

This prompt is automatically prepended to all `/imagen` generations in this project.

## Base Prompt

```
Dark fantasy digital art in the style of The Witcher III Gwent card game.
Color palette: charcoal background (#2a2a2a), burgundy accents (#6d1a36), antique gold highlights (#d4af37), dark brown borders (#5D4037), warm tan (#BCAAA4) and off-white (#EFEBE9) for secondary elements.
Aesthetic: medieval fantasy meets maker/hardware — weathered parchment textures, Celtic knotwork, aged metal, circuit board traces as runic patterns. Dramatic cinematic lighting, warm golden glow on key elements. No bright or neon colors. Rich, moody atmosphere.
```
