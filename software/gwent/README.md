# Gwent

Electronic version of the Gwent board game.

## Installation

```bash
pip install gwent
```

## Usage

```bash
# Run the main game
gwent

# Run the Novigrad server
novigrad

# Card operations
write_card
read_card
```

## Features

- Electronic card game with physical interface
- RFID card detection
- LED matrix display
- Audio feedback
- Rotary encoder input
