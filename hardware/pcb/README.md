# Gwent HAT — KiCad project

A Raspberry Pi 4 HAT carrier PCB for the Gwent Companion. Hosts headers and Qwiic connectors so the existing breakout modules (MFRC522, SSD1306 OLED, TCA9548A mux, three IS31FL3731 charlieplex matrices, PEC11 rotary encoder) plug in without re-soldering. Targets fabrication at JLCPCB.

> Canonical hardware spec: [`design/tasks/011-hardware-specification.md`](../../design/tasks/011-hardware-specification.md). If anything in the schematic conflicts with that doc, the doc wins — fix the schematic.

## Quick facts

| | |
|---|---|
| Form factor | Raspberry Pi HAT (65 × 56.5 mm) |
| Layers | 2 |
| Substrate | FR4, 1.6 mm, 1 oz copper, ENIG (or HASL for cheap) |
| Connectors | 2×20 GPIO stacking header, 1×8 RC522 header, 1×16 OLED header, 4× Qwiic JST-SH (mux + 3 matrices), PEC11 footprint |
| Library deps | KiCad 9 built-in libraries only (Connector, Connector_Generic, Connector_JST, Switch). SparkFun KiCad library optional for prettier Qwiic 3D models. |
| Power | 5V / 3.3V tapped from Pi GPIO header (no on-board regulator) |
| Target fab | JLCPCB, 5 boards (~$5 unassembled, ~$25 with header assembly) |

## Required tools

- **KiCad 9.x** — https://www.kicad.org/download/
- **git** with submodule support
- (optional) **JLCPCB plugin for KiCad** — https://github.com/Bouni/kicad-jlcpcb-tools — generates BOM and pick-and-place files in the format JLCPCB wants

Once KiCad is installed, open `gwent-hat.kicad_pro` and KiCad will pull in the project's symbol/footprint library tables (in `sym-lib-table` / `fp-lib-table`) which point at the vendored libs in `libs/`.

## First-time setup

```bash
cd hardware/pcb
open gwent-hat.kicad_pro          # macOS
# or
xdg-open gwent-hat.kicad_pro      # Linux
```

KiCad will create the schematic (`gwent-hat.kicad_sch`) and PCB (`gwent-hat.kicad_pcb`) on first save if they don't already exist. All symbols and footprints come from KiCad's bundled libraries — no extra setup required.

### Optional: SparkFun KiCad library (for nicer Qwiic visuals)

```bash
# From hardware/pcb/
git clone --depth 1 https://github.com/sparkfun/SparkFun-KiCad-Libraries.git libs/sparkfun-kicad
# Then in KiCad: Preferences → Manage Symbol Libraries → add libs/sparkfun-kicad
#                Preferences → Manage Footprint Libraries → add libs/sparkfun-kicad/footprints
```

This isn't required — KiCad's `Connector_JST:JST_SH_*` symbols are functionally equivalent — but the SparkFun version comes with proper Qwiic-branded silkscreen and 3D models.

## How the project is organized

| File | What it is |
|---|---|
| `gwent-hat.kicad_pro` | KiCad project metadata |
| `gwent-hat.kicad_sch` | Schematic |
| `gwent-hat.kicad_pcb` | PCB layout (board outline pre-drawn to Pi HAT spec) |
| `sym-lib-table` | Project-scoped symbol library list |
| `fp-lib-table` | Project-scoped footprint library list |
| `BUILD.md` | Step-by-step schematic placement guide |
| `BOM.md` | Bill of materials with manufacturer part numbers and JLCPCB/LCSC sourcing |
| `libs/` | (Optional) Vendored EDA libraries — only needed for SparkFun Qwiic visuals |
| `fab/` | Fabrication outputs (Gerbers, drill, BOM, CPL) — only versioned zips are committed |
| `docs/netlist.md` | Canonical net-by-net pin assignments — the source of truth for the schematic |

## Workflow

1. **Schematic** — open `gwent-hat.kicad_sch` and follow [`BUILD.md`](BUILD.md) step by step. Place every symbol from the BOM, wire nets per [`docs/netlist.md`](docs/netlist.md), assign footprints, run ERC.
2. **PCB layout** — Tools → Update PCB from Schematic. Footprints will appear inside the pre-drawn board outline. Place, route, run DRC. Match design rules to JLCPCB's "2-layer, 6/6 mil min trace, 0.3 mm min hole" capability tier.
3. **Fab outputs** — File → Plot → Gerbers (use the JLCPCB-friendly settings documented in `BUILD.md`), then File → Fabrication Outputs → Drill Files. Run the JLCPCB plugin to generate BOM + CPL CSVs.
4. **Order** — zip the Gerber/drill/BOM/CPL set into `fab/gwent-hat-v1.0-jlcpcb.zip`, upload to https://jlcpcb.com, pick stackup + finish + quantity, pay.
